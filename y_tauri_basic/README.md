# y_tauri_basic

## Tauri常用命令

| 命令 | 作用 |
|---|---|
| `npm install` | 安装前端依赖,首次获取项目后执行 |
| `npm run tauri dev` | 开发模式运行,修改代码后自动刷新或重新编译 |
| `npm run tauri build` | 打包发布版,安装包输出至`target/release/bundle/` |
| `npm run tauri add <插件名>` | 安装插件,并自动注册和授权 |
| `npm run tauri remove <插件名>` | 移除插件 |
| `npm run tauri icon <图片.png>` | 由一张图片生成全部图标 |
| `npm run tauri info` | 查看环境和版本信息,排查问题时使用 |
